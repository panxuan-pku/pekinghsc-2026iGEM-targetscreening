# Example inputs are obtained, not bundled

Follow the two complete workflows in the [main README](../README.md):

1. **WHS interval:** download the ClinGen GRCh38 region table, select ISCA-37429, then prepare references and screen.
2. **Gene list:** use your own sourced CSV/TSV/TXT, or convert all WHS candidates generated by the first workflow. The latter checks the second input route; it is not an independently sourced biological list.

Keep input files, source URLs and generated results under `workspace/screening/`. The standard interval is GRCh38, chr4:337779–2009235, 1-based inclusive. Do not reinterpret the historical 19-gene WHS set as this interval's complete candidate set.

For the independent public single-cell demonstration, follow [VCT data preparation](../docs/vct.md#3-prepare-the-public-example). PBMC is a tool demonstration, not a WHS patient dataset.
